# Slot Machine Game

A simple slot machine game made with Python and PyGame.

## Setup

1. Navigate to the project directory:
```
cd slot_machine_game
```

2. Install pygame:
```
pip install pygame
```

## How to Run

```
python main.py
```

## How to Play

- Press SPACE to spin
- Press Q to quit
- You start with $100
- Each spin costs $1
- Match 3 symbols to win $10!

## Running Tests

```
pip install pytest
pytest -v
```

## Symbols

- Cherry
- Lemon
- Orange
- Seven
